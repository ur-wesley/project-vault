# Project Vault

A desktop project manager -- like Steam, but for your local repositories. Import project folders, browse files, track git status, and manage GitHub issues, all in one window.

## Features

- Project library with full-text search, language filter, and favorites
- Git integration: status, push/pull, and semver tagging
- Version bump with automatic file updates and tag creation
- GitHub integration: issues and repository linking
- File browser with language-aware syntax highlighting
- Built-in terminal for each project
- README rendering
- Workspace analysis: language breakdown, size, and last activity
- Process monitor for background or long-running tasks
- Multi-language UI (English, German)

## Tech Stack

Tauri (Rust), SolidJS, TypeScript, SQLite, Tailwind CSS
